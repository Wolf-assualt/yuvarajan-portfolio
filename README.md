# Yuvarajan J — Portfolio V2

Animated developer-style portfolio inspired by a futuristic cybersecurity/developer dashboard.

## Included
- Responsive neon/dark UI
- Animated reveal effects and skill bars
- Hero terminal panel
- About facts
- Skills
- Projects
- Education
- Certifications
- Achievements
- Contact form UI
- GitHub links

## Important edits before publishing
Open `index.html` and replace:
- `YOUR_EMAIL@example.com`
- `+91 XXXXX XXXXX`
- LinkedIn / Instagram placeholder links
- Add your real resume as `resume.pdf` and change the CV button if desired.
- Review project/certificate details and percentages before using them publicly.

## GitHub Pages
Create a GitHub repository, add these files, commit, push, then:
Settings → Pages → Deploy from a branch → main → /(root) → Save.


## Add all your social links
Open `script.js` and edit only the `siteConfig` object at the top:
- `github`
- `linkedin`
- `instagram`
- `email`
- `phone`
- `terminal`
- `resume`
- `passwordProject`

The same links automatically update the buttons in the hero, project card and contact section.
